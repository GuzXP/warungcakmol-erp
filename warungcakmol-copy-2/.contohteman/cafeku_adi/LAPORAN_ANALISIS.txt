1. ANALISIS SISTEM BERJALAN
================================================================================

1.1 LATAR BELAKANG SISTEM LAMA
   Sebelum adanya aplikasi CAFEKU, proses manajemen cafe dilakukan secara manual:
   - Pencatatan pesanan di buku
   - Perhitungan harga manual oleh kasir
   - Manajemen inventori produk tidak terstruktur
   - Laporan penjualan dicatat manual di kertas
   - Pengelolaan data karyawan dan gaji menggunakan spreadsheet
   - Belum ada sistem pemesanan online

1.2 MASALAH PADA SISTEM LAMA
   - Proses lambat dan tidak efisien (manual entry)
   - Rentan terjadi kesalahan perhitungan
   - Sulit melacak riwayat transaksi
   - Tidak ada analisis data penjualan real-time
   - Pengelolaan inventori produk tidak akurat
   - Kesulitan dalam pembuatan laporan keuangan
   - Tidak ada opsi pemesanan online untuk pelanggan
   - Data tersebar di berbagai tempat (tidak terpusat)
   - Skalabilitas terbatas

1.3 PROSES BISNIS SAAT INI
   A. PROSES PENJUALAN:
      - Pelanggan datang ke cafe
      - Kasir mencatat pesanan secara manual
      - Perhitungan total harga manual
      - Pembayaran tunai
      - Pencatatan transaksi di buku kasir
   
   B. MANAJEMEN PRODUK:
      - Stok produk dicatat di buku
      - Pembelian stok tanpa sistem terstruktur
      - Tidak ada laporan stok real-time
   
   C. MANAJEMEN KARYAWAN:
      - Data karyawan di spreadsheet
      - Perhitungan gaji manual
      - Tugas belanja tidak terorganisir

1.4 STAKEHOLDER SISTEM LAMA
   - Pemilik Cafe (Galin Widya)
   - Kasir
   - Barista
   - Pelanggan
   - Kepala Gudang

2. ANALISIS SISTEM USULAN
================================================================================

2.1 VISI SISTEM USULAN
   Membangun sistem informasi terintegrasi untuk meningkatkan efisiensi operasional
   cafe, mempercepat layanan pelanggan, dan menyediakan kemudahan dalam manajemen
   bisnis cafe secara digital dan real-time.

2.2 MISI SISTEM USULAN
   - Menyediakan platform pemesanan online untuk memudahkan pelanggan
   - Mengotomasi proses penjualan dan perhitungan transaksi
   - Mengelola inventori produk secara akurat dan real-time
   - Menyediakan laporan penjualan dan keuangan yang akurat
   - Meningkatkan efisiensi pengelolaan karyawan dan gaji
   - Menyediakan analisis data untuk pengambilan keputusan bisnis
   - Meningkatkan keamanan data dengan sistem login terenkripsi

2.3 KEUNGGULAN SISTEM USULAN
   - Proses transaksi lebih cepat dan akurat
   - Data terpusat dalam satu database
   - Laporan real-time dapat diakses kapan saja
   - Peningkatan kepuasan pelanggan dengan pemesanan online
   - Pengurangan kesalahan manusia
   - Kemudahan dalam analisis data penjualan
   - Manajemen karyawan lebih terstruktur
   - Keamanan data terjamin dengan enkripsi password

2.4 PLATFORM TEKNOLOGI
   - Backend: PHP 8.3.30
   - Database: MySQL 8.4.3
   - Frontend: HTML5, CSS3, JavaScript
   - Server: Apache (XAMPP)
   - Sistem Operasi: Windows
   - Browser: Cross-platform compatible

3. KEBUTUHAN FUNGSIONAL
================================================================================

3.1 KEBUTUHAN FUNGSIONAL UNTUK PELANGGAN (USER)
   F1.1 Autentikasi Pelanggan
        - Pelanggan dapat mendaftar akun baru
        - Pelanggan dapat login dengan username dan password
        - Pelanggan dapat logout dari sistem
        - Sistem mengenkripsi password menggunakan bcrypt
        - Fitur "Remember Me" untuk login otomatis
   
   F1.2 Browsing Katalog Menu
        - Menampilkan semua menu cafe
        - Filter menu berdasarkan kategori (Coffee, Non-Coffee, Pastry, Mocktail, Alcohol)
        - Menampilkan detail produk (nama, harga, deskripsi, gambar)
        - Fitur pencarian menu (opsional)
   
   F1.3 Manajemen Keranjang Belanja
        - Menambah produk ke keranjang
        - Mengubah jumlah (qty) produk di keranjang
        - Menghapus produk dari keranjang
        - Mengosongkan seluruh keranjang
        - Menampilkan ringkasan total harga
   
   F1.4 Checkout dan Pembayaran
        - Menampilkan detail pesanan
        - Menampilkan perhitungan total dengan PPN 10%
        - Proses konfirmasi pembayaran
        - Cetak struk/invoice
   
   F1.5 Riwayat Pesanan
        - Menampilkan history pesanan pelanggan
        - Detail setiap transaksi (tanggal, produk, total)

3.2 KEBUTUHAN FUNGSIONAL UNTUK ADMIN
   F2.1 Autentikasi Admin
        - Admin dapat login dengan username dan password
        - Admin dapat logout dari sistem
        - Proteksi halaman admin dengan session check
   
   F2.2 Dashboard Admin
        - Menampilkan informasi overview (total penjualan, produk terbanyak)
        - Shortcut ke semua menu admin
   
   F2.3 Manajemen Produk
        - Menampilkan list semua produk
        - Menambah produk baru (nama, harga, kategori, deskripsi, gambar)
        - Edit produk (mengubah data produk)
        - Hapus produk
        - Cari produk berdasarkan keyword
   
   F2.4 Manajemen Kategori
        - Menampilkan kategori produk
        - Menambah kategori baru
        - Edit kategori
        - Hapus kategori
   
   F2.5 Sistem Kasir
        - Mencatat penjualan dari pelanggan
        - Menambah produk ke pesanan
        - Mengubah qty pesanan
        - Menghitung total otomatis
        - Proses pembayaran
        - Cetak struk pembayaran
   
   F2.6 Manajemen Laporan
        - Laporan penjualan harian/mingguan/bulanan
        - Laporan produk terlaris
        - Laporan kategori paling diminati
        - Export laporan ke Excel/PDF
   
   F2.7 Manajemen Karyawan
        - Menampilkan list karyawan
        - Menambah data karyawan baru
        - Edit data karyawan
        - Hapus data karyawan
        - Pencarian data karyawan
   
   F2.8 Manajemen Gaji Karyawan
        - Input gaji karyawan
        - Perhitungan gaji otomatis
        - Laporan gaji
        - History pembayaran gaji
   
   F2.9 Pengelolaan Pembelian Stok
        - Mencatat pembelian produk dari supplier
        - Input biaya pembelian
        - Update stok produk otomatis
        - Laporan pembelian
   
   F2.10 Manajemen Uang Masuk/Keluar
         - Mencatat pemasukan (penjualan, lainnya)
         - Mencatat pengeluaran (operasional, gaji)
         - Laporan cash flow
   
   F2.11 Tugas Belanja
         - Membuat list tugas belanja
         - Menandai tugas selesai
         - Laporan tugas belanja

3.3 KEBUTUHAN FUNGSIONAL SISTEM

        - Menyimpan data produk, user, keranjang, transaksi
        - Backup data regular
        - Integritas data terjamin

        - Notifikasi pesanan baru ke admin
        - Notifikasi pembayaran sukses ke pelanggan (opsional)

6. SKENARIO USE CASE DIAGRAM
================================================================================

SKENARIO 1: USER MENDAFTAR AKUN BARU
Aktor Utama: User (Pelanggan)
Tujuan: Membuat akun baru untuk pemesanan
Precondition: User belum memiliki akun
Flow Utama:
  1. User membuka halaman login
  2. User klik tombol "Buat Akun Baru"
  3. Sistem menampilkan form registrasi
  4. User mengisi form (Nama, Username, Password, Konfirmasi Password)
  5. User klik "DAFTAR"
  6. Sistem validasi input:
     - Jika ada field kosong → Tampilkan error "Semua field harus diisi"
     - Jika password < 5 karakter → Tampilkan error "Password minimal 5 karakter"
     - Jika password tidak sesuai → Tampilkan error "Konfirmasi password tidak sesuai"
     - Jika username sudah ada → Tampilkan error "Username sudah terdaftar"
  7. Jika valid, sistem hash password dan simpan ke database
  8. Sistem tampilkan pesan sukses
  9. Sistem redirect ke login page setelah 2 detik
Postcondition: Akun user berhasil dibuat, siap login

SKENARIO 2: USER LOGIN DAN MEMESAN
Aktor Utama: User (Pelanggan)
Tujuan: Login dan melakukan pemesanan menu
Precondition: User sudah memiliki akun
Flow Utama:
  1. User membuka halaman login
  2. User masuk username dan password
  3. User (opsional) check "Remember Me"
  4. User klik "LOGIN"
  5. Sistem validasi kredensial:
     - Jika username tidak ada → Tampilkan error
     - Jika password salah → Tampilkan error
  6. Jika valid, sistem buat session dan (opsional) set cookie
  7. Sistem redirect ke halaman user/index.php
  8. User dapat melihat katalog menu dengan kategori:
     - All Menu, Coffee, Non Coffee, Pastry, Mocktail, Alcohol
  9. User klik produk untuk lihat detail
  10. User klik "Tambah ke Keranjang"
  11. Sistem tambah produk ke keranjang dan tampilkan alert sukses
  12. User dapat tambah produk lain dengan cara yang sama
  13. User klik tombol "Keranjang"
  14. Sistem tampilkan daftar produk di keranjang dengan qty controls
  15. User dapat ubah qty atau hapus produk
  16. Sistem hitung total otomatis (dengan PPN 10%)
  17. User klik "CHECKOUT"
  18. Sistem proses pembayaran dan tampilkan struk
  19. User dapat cetak struk
Postcondition: Pesanan berhasil dibuat, user dapat menerima struk

SKENARIO 3: ADMIN KELOLA PRODUK
Aktor Utama: Admin
Tujuan: Menambah produk baru ke sistem
Precondition: Admin sudah login
Flow Utama:
  1. Admin klik menu "Dashboard"
  2. Admin klik "Produk" atau link yang sesuai
  3. Sistem tampilkan list produk
  4. Admin klik "Tambah Produk"
  5. Sistem tampilkan form tambah produk dengan field:
     - Nama produk
     - Harga
     - Kategori (dropdown)
     - Deskripsi
     - Gambar (upload)
  6. Admin isi form
  7. Admin klik "SIMPAN"
  8. Sistem validasi data:
     - Jika ada field wajib kosong → Error
     - Jika harga bukan angka → Error
     - Jika gambar > 5MB → Error
  9. Jika valid, sistem upload gambar dan simpan data ke database
  10. Sistem tampilkan pesan sukses
  11. Admin redirect ke list produk, produk baru muncul di list
Postcondition: Produk baru berhasil ditambahkan ke sistem

SKENARIO 4: ADMIN BUAT LAPORAN PENJUALAN
Aktor Utama: Admin
Tujuan: Membuat laporan penjualan untuk analisis
Precondition: Admin sudah login, ada data transaksi
Flow Utama:
  1. Admin klik menu "Laporan"
  2. Sistem tampilkan form filter laporan dengan opsi:
     - Periode (Harian, Mingguan, Bulanan)
     - Tanggal dari - sampai
     - Kategori produk (opsional)
  3. Admin pilih filter yang diinginkan
  4. Admin klik "GENERATE LAPORAN"
  5. Sistem query database dan hitung total penjualan
  6. Sistem tampilkan laporan dengan detail:
     - Total penjualan
     - Produk terlaris
     - Kategori paling diminati
     - Grafik penjualan
  7. Admin dapat pilih export ke Excel/PDF
  8. Sistem generate file dan trigger download
  9. File berhasil didownload ke computer admin
Postcondition: Laporan penjualan berhasil dibuat dan diexport

SKENARIO 5: ADMIN KELOLA KARYAWAN & GAJI
Aktor Utama: Admin
Tujuan: Mengelola data karyawan dan perhitungan gaji
Precondition: Admin sudah login
Flow Utama - Kelola Karyawan:
  1. Admin klik menu "Karyawan"
  2. Sistem tampilkan list karyawan
  3. Admin dapat:
     - Tambah karyawan baru (nama, posisi, gaji, dll)
     - Edit data karyawan
     - Hapus karyawan
  4. Setiap perubahan disimpan ke database
Flow Utama - Perhitungan Gaji:
  1. Admin klik menu "Gaji Karyawan"
  2. Sistem tampilkan list karyawan dengan gaji default
  3. Admin dapat input bonus/potongan gaji
  4. Sistem kalkulasi gaji total otomatis
  5. Admin klik "PROCESS PAYROLL"
  6. Sistem buat slip gaji dan catat di database
  7. Admin dapat cetak slip gaji atau export ke Excel
  8. Email notifikasi dikirim ke karyawan (opsional)
Postcondition: Data karyawan terupdate dan gaji ter-process

7. SKENARIO DIAGRAM (SEQUENCE DIAGRAM)
================================================================================

SEQUENCE 1: PROSES LOGIN USER
User → Login Page → System → Database
  User: Input username & password
  Login Page: Trim & sanitize input
  System: Prepare statement query
  Database: SELECT * FROM users WHERE username = ?
  Database: Return user record
  System: password_verify() check
  IF valid:
    System: $_SESSION['login'] = true
    System: $_SESSION['role'] = 'user'
    System: Redirect ke index.php
    System: index.php auto-redirect ke user/index.php
    User: Lihat katalog menu
  IF invalid:
    System: $error = true
    Login Page: Tampilkan error "Username/Password salah"

SEQUENCE 2: PROSES TAMBAH PRODUK KE KERANJANG
User → Menu Page → Session → Database
  User: Klik "Tambah ke Keranjang"
  Menu Page: GET id produk dari URL
  Session: Check $_SESSION['login']
  IF not login:
    Redirect ke login.php
  ELSE:
    Database: SELECT * FROM produk WHERE id = ?
    Database: Check if produk already in keranjang
    IF ya:
      Database: UPDATE keranjang SET qty = qty + 1
    IF tidak:
      Database: INSERT INTO keranjang (produk_id, qty) VALUES (?, 1)
    System: Alert sukses "Berhasil ditambah ke keranjang"
    Page: Redirect ke index.php

SEQUENCE 3: PROSES CHECKOUT & PEMBAYARAN
User → Pembayaran Page → Session → Database
  User: Klik "CHECKOUT"
  Pembayaran Page: Session check
  Database: SELECT * FROM keranjang JOIN produk
  System: Kalkulasi subtotal
  System: Kalkulasi PPN = subtotal * 10%
  System: TOTAL = subtotal + PPN
  Pembayaran Page: Tampilkan detail pesanan & total
  User: Review pesanan
  User: Klik "BAYAR"
  Database: INSERT INTO transaksi
  Database: DELETE FROM keranjang (clear keranjang)
  System: Generate struk
  System: Trigger print/download struk
  User: Terima struk digital
  Pembayaran Page: Tampilkan "Terima kasih, pesanan Anda sedang diproses"

SEQUENCE 4: PROSES ADMIN TAMBAH PRODUK
Admin → Admin Page → Form → Database
  Admin: Klik "Tambah Produk"
  Admin Page: Tampilkan form dengan field
  Admin: Isi form (nama, harga, kategori, deskripsi, gambar)
  Admin: Klik "SIMPAN"
  Form: Validasi client-side
  System: $_FILES['gambar'] upload ke folder poto/
  System: Server-side validation
  IF invalid:
    System: Alert error
  IF valid:
    Database: INSERT INTO produk VALUES
    Database: Return insert ID
    System: Alert sukses
    Admin Page: Tampilkan produk baru di list

SEQUENCE 5: PROSES GENERATE LAPORAN PENJUALAN
Admin → Laporan Page → Database → Report Engine
  Admin: Klik menu "Laporan"
  Laporan Page: Tampilkan form filter
  Admin: Pilih periode & filter
  Admin: Klik "GENERATE"
  Database: SELECT COUNT, SUM FROM transaksi
  Database: Filter berdasarkan date range
  Report Engine: Kalkulasi statistik
  Report Engine: Generate tabel & grafik
  Laporan Page: Tampilkan laporan interaktif
  Admin: Klik "EXPORT EXCEL"
  System: Gunakan library PHPExcel/SimpleXLSX
  System: Generate file .xlsx
  System: Header Content-Disposition: attachment
  Browser: Trigger download file
  Admin: File berhasil didownload

KESIMPULAN
================================================================================

Sistem CAFEKU dirancang untuk meningkatkan efisiensi operasional cafe dengan 
mengotomasi proses penjualan, manajemen inventori, pengelolaan karyawan, dan 
pelaporan. Dengan fitur online ordering, pelanggan dapat dengan mudah memesan 
menu, dan admin dapat mengelola bisnis secara terpusat melalui dashboard.

Keamanan data terjamin dengan enkripsi password, session management, dan 
validasi input. Sistem dapat dengan mudah dikembangkan untuk menambah fitur baru 
sesuai kebutuhan bisnis di masa depan.

Target Implementasi:
- Fase 1: Core functionality (Login, Produk, Keranjang, Pembayaran)
- Fase 2: Admin features (Laporan, Karyawan, Gaji)
- Fase 3: Advanced features (Analytics, Mobile App, API Integration)
